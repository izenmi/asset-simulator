# AssetForge - 資産形成＆FIRE詳細シミュレーター

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-emerald?style=flat-square&logo=github)](https://izenmi.github.io/asset-simulator/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

**AssetForge（アセットフォージ）** は、退職金・市場暴落ショック・サイドFIRE副収入・新NISA非課税枠と特定口座の税金分離・公的年金繰上げ/繰下げ・ライフイベント一時収支・モンテカルロ分析（確率分布・破綻率計算）まで完全網羅した、最高峰の資産形成＆FIREシミュレーションWebツールです。

🔗 **公開URL（GitHub Pages）**: [https://izenmi.github.io/asset-simulator/](https://izenmi.github.io/asset-simulator/)

---

## 🌟 特徴と機能一覧

### 1. デュアルモード（Standard & Advance）
- **Standard（基本）モード**:
  - 初心者でも30秒で結果が出るシンプルUI。
  - 現在年齢、リタイア予定年齢、現在資産、毎月の積立額、想定利回り、リタイア後の生活費を入力するだけで即座にグラフ・達成判定を可視化。
- **Advance（詳細）モード**:
  - トグル1つでプロフェッショナルな変数をフルオープン。
  - **退職金・退職一時金**: 受取年齢、額面、勤続年数に応じた日本の「退職所得控除」を忠実に自動計算し、税引後手取り額を反映。
  - **暴落予想（市場ショック）**: 発生年齢（例: 45歳）、下落率（例: -35%）、回復年数（例: 3年）を指定。暴落時の投資行動（「積立継続」「追加スポット買い増し」「恐怖で積立停止」）もシミュレーション可能。
  - **サイドFIRE / 副収入・事業所得**: リタイア後に月いくら稼ぐか（例: 月8万円）、何歳まで稼ぐかを指定し、取り崩しを大幅に抑制する効果を可視化。
  - **公的年金（国民・厚生）**: 65歳基準の受取見込み額と、受給開始年齢（60〜75歳）による「繰上げ減額（月-0.4%）」「繰下げ増額（月+0.7%）」を自動計算。社保・税引き手取りを算出。
  - **新NISA枠と特定口座の分離**: 生涯非課税枠（1,800万/3,600万）と特定口座を自動振り分け。取り崩し時の運用益課税（20.315%）を考慮。
  - **インフレ率（物価上昇）**: 名目金額（将来の円）と実質購買力（現在価値換算）をワンクリック切り替え。
  - **積立年次ステップアップ**: 昇給・キャリアアップに伴う毎年の積立額増額率（例: 年1〜2%）。
  - **ライフイベント（一時収支）**: マイホーム購入（頭金）、子供の大学進学費用、車の買い替え、遺産相続などを自由に複数追加・管理。

### 2. 充実のビジュアライゼーション（Chart.js）
- **資産推移チャート**: 資産総額カーブ、累計積立元本ライン、暴落直撃ポイントのハイライト表示。
- **モンテカルロ信頼区間ファンチャート**: 株式市場のボラティリティ（リスクσ15%）を加味した1,000回の試行から、「上位10%好調」「上位25%」「中央値（50%）」「下位25%」「最悪10%不調」の確率ゾーンを可視化。
- **年間収支（キャッシュフロー）バーチャート**: 年毎の「収入/積立」vs「支出/取り崩し」を視覚的に比較。

### 3. KPIカード＆インサイト
- リタイア時総資産（元本比 +○%）
- 人生終了時（想定寿命）の残存資産（名目＆実質）
- FIRE達成判定（4%ルールクリア度、FIRE達成可能年齢）
- 資産枯渇リスク（破綻確率%、何歳まで安泰か）
- シミュレーション分析とアドバイス文章の自動生成

### 4. 便利機能
- **5大プリセット**:
  1. 👑 王道FIRE（新NISA全力）
  2. ☕ サイドFIRE（月8万副業）
  3. 🏛️ 堅実公務員（退職金・年金手厚い）
  4. ⚡ 暴落耐性（リタイア直前のリーマン級ショック直撃）
  5. 🛡️ 保守型（現金多め・年金繰り下げ）
- **URL共有**: パラメータをURLハッシュに暗号化保存。リンクを送るだけで同じシミュレーションを共有可能。
- **CSVダウンロード**: 全期間の年別キャッシュフロー表をUTF-8 BOM付きExcel対応CSVで出力。
- **LocalStorage自動保存**: ブラウザをリロードしても前回の入力値を維持。
- **ダークモード / ライトモード**: システム設定または手動で瞬時に切替。
- **印刷最適化（A4レポート）**: 印刷時に不要なUIを隠し、グラフと結果を美しくA4出力。

## 🚀 ローカルでの動かし方

依存パッケージやビルドステップは不要です。ブラウザで `index.html` を直接開くだけで動作します。

```bash
# クローン
git clone https://github.com/izenmi/asset-simulator.git
cd asset-simulator

# 任意のローカルサーバー（または index.html を直接ダブルクリック）
python -m http.server 8080
# http://localhost:8080 をブラウザで開く
```

## 🛠️ 技術スタック
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS (Play CDN)
- **Charts**: Chart.js 4.4
- **Icons**: Lucide Icons
- **Math/Simulation**: 幾何ブラウン運動（Box-Muller正規乱数生成）によるモンテカルロ法、日本の退職所得税法・年金法準拠の計算モデル
